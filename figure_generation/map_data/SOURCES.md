# Boundary data used by Figure 1

- California: US Census Bureau, 2025 Cartographic Boundary Files, state layer at 1:500,000 (`cb_2025_us_state_500k`).
  Source: https://www.census.gov/geographies/mapping-files/2025/geo/carto-boundary-file.html
- India: Natural Earth, Admin 0 - Countries at 1:50 million, version 5.1.1 (`ne_50m_admin_0_countries`).
  Source: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/

Both boundaries are used as geographic context only. The plotted task coordinates come directly from the frozen simulation task file.
