# Thesis Figure Generator

This package recreates the full thesis figure set directly in Python/Matplotlib. It implements Vincenzo's figure feedback: exported plots instead of screenshots, substantially larger text and numbers, proper formatting, and meaningful captions.

## Output

The package generates **22 report figures**:

1. Task-location map
2. Campaign and scenario coverage
3. Regional response to Central Node fraction
4. Central Node regression fit
5. Paired California--India performance
6. Two-region Pareto landscape
7. Central Node performance by constellation size
8. Architecture-factor main effects
9. Spearman correlation heatmap
10. Routing-policy ablation
11. Task-size sensitivity
12. Priority-specific outcomes
13. Robustness response
14. Unlimited-policy Pareto trade space
15. Objective-weight sweep
16. Monte Carlo winner frequency
17. Mission chain
18. Task-generation workflow
19. Simulation and post-processing workflow
20. Walker constellation and Central Nodes
21. Temporal routing example
22. Scenario and failure transformation flow

Every figure is exported as:

- `png/`: 300 dpi raster image for Word/PowerPoint
- `pdf/`: vector figure for LaTeX
- `FIGURE_MANIFEST.csv`: filename, data source, sample definition, and proposed caption
- `CAPTION_GUIDE.md`: ready-to-adapt LaTeX caption text
- `companion_tables/`: numerical results kept out of crowded plot areas

## Formatting rules enforced by the code

- No long title inside a figure.
- No filename, Windows/Linux path, raw case identifier, raw scenario identifier, or raw column name printed in a plot.
- Human-readable axis names and units only.
- Large, consistent sans-serif type (Arial/TeX Gyre Heros fallback chain).
- TUM-compatible restrained colour palette.
- Engineering-style explanatory diagrams: rectangular geometry, straight connectors, minimal fills, and no decorative rainbow node colouring.
- `Central Node` is the consistent user-facing term in figures and captions.
- Region and constellation size use separate visual encodings (colour versus line style/marker) in the principal comparison figure.
- Legends outside the data area when they would obscure observations.
- Direct exports; do not take screenshots.
- Full explanations, assumptions, and the 180-satellite task-population note belong in the LaTeX caption or body text.

## Required input

The analytical figures use the canonical post-processing table:

`tables/canonical_completed_rows_all_supplied_regions.parquet`

This is generated by the complete post-processing pipeline. The script also needs the task-coordinate CSV used by the simulation, normally:

`input_tasks/all_sentinel3_tasks_with_priority_score_deduplicated.csv`

If a priority-stratified result is not available, Figure 12 states that honestly instead of inventing values.

## Run on Windows

Open PowerShell in this package folder and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN_WINDOWS.ps1 `
  -AnalysisRoot "C:\path\to\postprocessing_output" `
  -TasksCsv "C:\path\to\all_sentinel3_tasks_with_priority_score_deduplicated.csv" `
  -Output "C:\path\to\thesis_figures"
```

The script creates its own Python environment and installs only Matplotlib, NumPy, pandas, and PyArrow.

## Run directly with Python

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe generate_thesis_figures.py `
  --analysis-root "C:\path\to\postprocessing_output" `
  --tasks-csv "C:\path\to\tasks.csv" `
  --output "C:\path\to\thesis_figures"
```

Use `--only diagrams` to create just the six explanatory diagrams or `--only analysis` to create the 16 data-driven figures.

## Validate before using real results

Run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN_DEMO_WINDOWS.ps1
```

The demo creates representative synthetic data and exercises all 22 figure functions. Demo numbers must never be used in the thesis; they exist only to verify the plotting package and formatting.

## Using the figures in LaTeX

Prefer the vector PDF files:

```latex
\begin{figure}[t]
  \centering
  \includegraphics[width=\textwidth]{figures/pdf/07_central_node_performance.pdf}
  \caption{Use the corresponding entry from CAPTION_GUIDE.md and adapt it to the chapter context.}
  \label{fig:central-node-performance}
\end{figure}
```

Do not put the report's full caption into the Matplotlib image. Keeping it in LaTeX preserves TUM typography, accessibility, cross-references, and consistent spacing.
