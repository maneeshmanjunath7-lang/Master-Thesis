This thesis uses a final two-layer evidence policy so that every claim is tied to a scientifically consistent analysis population. The policy preserves the completed simulations while preventing an input inconsistency in the India 180-satellite run from being interpreted as a controlled fleet-size experiment.

\begin{enumerate}
\item The earlier nominal campaign in Chapter~6 is retained as an independently validated historical baseline.
\item The confirmatory Fresh V2 analysis contains the 60- and 120-satellite layers: 54 base architectures, 594 cases per event window, and 640,332 case-scenario evaluations across the California and India event-window cases. California uses 32 tasks and India uses the intended 773 tasks throughout this layer. Regional contrasts, the principal Pareto analysis, and the main cross-window shortlist are based on this population.
\item The exploratory India 180-satellite analysis contains 282 computationally complete cases and 151,998 case-scenario evaluations, all using the same realized population of 741 India tasks. The balanced architecture block contains 216 cases: 27 base architectures at the eight common Central Node fractions CN30--CN100. CN-response, robustness, priority timing, Pareto, and rank-acceptability summaries for this layer use that balanced block.
\end{enumerate}

The intended India population contains 773 tasks. The 32 omitted rows in the exploratory run are all Low-priority tasks from 16 April 2026. The root cause was index alignment during task normalization. After the India rows were filtered from the combined file, their labels remained 32--804. A new 0--772 output table was then populated from those labelled series, so pandas aligned by label instead of row position. This created 32 invalid leading rows and excluded the final 32 India tasks. The completed 180-satellite computations are therefore valid descriptions of a consistent 741-task experiment, but they do not pass the intended 773-task contract.

The 282-case set is not balanced at the three lowest Central Node fractions: 20 cases are available at CN0, 22 at CN10, and 24 at CN20. All 27 base architectures are available from CN30 through CN100. The low-CN cases remain reproducible completed results, but they are not used in aggregate architecture rankings because unequal base coverage would change the weighting of the design grid.

This evidence policy has four consequences. First, California--India statements and formal workload contrasts are confined to the confirmatory 60/120-satellite layer. Second, the 180-satellite findings are explicitly conditional on the 741-task India workload. Third, no clean 120-to-180 fleet-size coefficient or California--India contrast at 180 satellites is claimed. Fourth, the exploratory 180-satellite shortlist is reported separately and is not merged with the confirmatory cross-window shortlist.

Observation-radius, alternative-placement, task-model, routing-package-component, multi-ground-station, and stochastic-replicate-extension experiments were not part of the final evidence supplied for this thesis. Their absence does not invalidate the stated baseline analyses, but it limits the conclusions to the implemented package, deterministic placement, fixed \SI{700}{\kilo\metre} access proxy, selected event windows, and retained replicate counts. These boundaries are carried through the Results, Discussion, Conclusions, and validation appendix.
