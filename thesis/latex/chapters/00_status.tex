This thesis uses a final evidence policy in which every claim is tied to a validated task population and a balanced architecture population.

\begin{enumerate}
\item The earlier nominal campaign in Chapter~6 is retained as an independently validated historical baseline.
\item The final regional block contains the 60- and 120-satellite cases: 54 base architectures, 594 cases per event window, and 640,332 case-scenario evaluations across California and India. California uses 32 tasks and India uses 773 tasks throughout this block. Regional contrasts, the principal Pareto analysis, and the cross-window portfolio core use this population.
\item The same verified campaign includes an India 180-satellite extension with 282 cases and 151,998 case-scenario evaluations. Every case uses the intended 773-task India population. Its balanced architecture block contains 216 cases: 27 base architectures at the eight common Central Node fractions CN30--CN100. Central Node response, robustness, priority timing, Pareto, and matched 120-to-180 comparisons use this block.
\end{enumerate}

The 180-satellite package passed its run contract and input-provenance checks: 282 of 282 selected cases are complete, each case declares 539 scenarios, the normalized task count is 773, and no failed case was retained. This replaces the earlier 741-task execution, which resulted from index alignment during task normalization. The earlier output is retained only as development history and is not used for final numerical claims.

The corrected 282-case set is still not balanced at the three lowest Central Node fractions: 20 cases are available at CN0, 22 at CN10, and 24 at CN20. All 27 base architectures are available from CN30 through CN100. The low-CN cases remain reproducible completed results, but they are excluded from aggregate architecture rankings because unequal base coverage would change the weighting of the design grid.

This evidence policy has four consequences. First, California--India statements are confined to the matched 60/120-satellite block because no California 180-satellite population was executed. Second, India 120-to-180 effects are calculated only for the 216 matched CN30--CN100 architecture cells and the common 773-task contract. Third, the 180-satellite Pareto candidates extend the final portfolio but are not treated as universal optima. Fourth, conclusions below CN30 at 180 satellites remain case-level rather than balanced-grid statements.

Observation-radius, alternative-placement, task-model, routing-package-component, multi-ground-station, and stochastic-replicate-extension experiments were not part of the final evidence supplied for this thesis. Their absence does not invalidate the stated baseline analyses, but it limits the conclusions to the implemented package, deterministic placement, fixed \SI{700}{\kilo\metre} access proxy, selected event windows, and retained replicate counts. These boundaries are carried through the Results, Discussion, Conclusions, and validation appendix.
